Leave this panel open

    Settings
    Send to Claude Code

    Turns the frames you select into a built screen. Measurements, tokens and assets are read from the Figma file itself, never from a screenshot.

    Status

      Where builds go

      Default folder …

      New folders are created here. Any single build can go elsewhere — choose Select Folder… when you send it.

      How to use it

      1. Select one or more frames on the canvas, or a section to send everything inside it.
      2. Check the list of screens, and choose where it should build.
      3. Press Send to Claude Code. Claude Code opens with the brief loaded.
      4. Press Enter there to start the build. Nothing runs until you do.
